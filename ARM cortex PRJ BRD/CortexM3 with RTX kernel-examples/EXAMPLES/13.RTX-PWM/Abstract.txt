In this RTX example PWM controlling is done using periodic time interval function as well as PWM 
interrupt which sets required event for task1 that wake up the tasks for every 0.5 sec. this is done
by The os_itv_wait function it waits for a periodic time interval after which the RTX kernel wakes
up the calling task. You must set the time interval using the os_itv_set function.

you can use the os_itv_wait function to perform a job at regular intervals independent of the execution time of the task.
isr_evt_set(0x0001, tsk1); function is used to set an event for task1. 


The task1 runs for every 0.5sec to generate Pulse width continuously updating ON period of 1msec.
