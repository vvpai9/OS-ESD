This is a simple RTX Kernel based example that uses an event which is set in the 
TIMER0_IRQHandler this signals a task1 which is waiting on this event.
 
The task1 toggles the RLY2 and L12 and again waits on the event for every 2sec.

The init_task creates the task1 and deletes itself as it is no longer required. 

The interrupt function is written in the same normal way.
