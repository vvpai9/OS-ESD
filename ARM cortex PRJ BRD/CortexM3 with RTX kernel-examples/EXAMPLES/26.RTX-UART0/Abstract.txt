This is a simple RTX Kernel based example that uses an event which is set in the UART0 ISR
whenever any key pressed from PC key board. 

This signals a task1 which is waiting on this event. 
whenever any key pressed from PC key board. characters are displayed 
on hyper terminal and task1 toggles the RLY2 and L12 and again waits on the event.

The init_task creates the task1 and deletes itself 
as it is no longer required. 

The interrupt function is written in the same normal way.
